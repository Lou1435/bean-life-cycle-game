# 🌱 Bean Life Cycle Ordering Game

An interactive educational game where players drag bean life cycle stages into the correct order, from seed to new seeds!

## How to Play

1. **View the stages** - Six different stages of the bean plant life cycle are displayed as draggable cards
2. **Drag the cards** - Click and drag each card to one of the numbered slots below
3. **Order them correctly** - Arrange them in the correct sequence:
   - 1. Seed
   - 2. Germination
   - 3. Seedling
   - 4. Bean pods
   - 5. Flowering
   - 6. New seeds
4. **Check your answer** - Click "Check my order ✓" to see if you got it right
5. **Try again** - Click "Try again ⟳" to reset and play again

## Game Features

✅ Drag-and-drop interface
✅ Instant feedback on answers
✅ Responsive design (works on mobile and desktop)
✅ Educational content about plant biology
✅ Fun emoji-based graphics
✅ No external dependencies - pure HTML/CSS/JavaScript
